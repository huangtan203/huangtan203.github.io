你好，欢迎来到我的博客。

我是一名嵌入式 MCU 软件工程师，工作四年半，日常和 Cortex-M、裸机 / RTOS、外设驱动打交道。这个博客记录我从「用芯片」走向「懂芯片」的过程。

## 为什么写

工作越久越发现，嵌入式工程师往上走，拼的不是调过多少外设，而是对底层的理解：

- datasheet 里一行时序参数的背后，硬件到底发生了什么
- 中断延迟到底消耗在哪一级流水线
- 一段代码跑得慢，是总线、是缓存、还是编译器的问题

这些问题停留在寄存器层面，永远只能背答案。所以我参加了「一生一芯」，从零写一颗 RISC-V 处理器，把体系结构知识从「看过」变成「做过」。

## 会写什么

1. **一生一芯系列**——流水线设计、difftest 调试实录、踩坑记录，按学习进度连载
2. **MCU 踩坑实录**——工作中真实定位过的硬件 / 驱动 bug，过程比结论有价值
3. **工具链实战**——交叉编译、链接脚本、CMake / Makefile 工程模板

不追求日更，只写真问题。每篇文章对应的代码都会同步到 GitHub 仓库，欢迎 Issue 交流。
